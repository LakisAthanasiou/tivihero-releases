# TiviHero beta builds

Signed private beta builds of TiviHero for Android TV. This repository holds only release APKs and `update.json`, which installed betas read to offer updates.

- Each beta stops working 14 days after it is built; install the latest version from the app (Settings > About) or from Releases.
- TiviHero is a player only. You need your own IPTV provider account.
- Moving from IPTV Hero: update IPTV Hero, then open Settings > About > Move to TiviHero.
- Source code is not published here.
